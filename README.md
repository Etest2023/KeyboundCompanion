# 迪迦版

## 功能
- **自动间隔提交**：默认开启，只能手动取消勾选关闭；无法输入时自动暂停，恢复后继续。
- **延迟滑块**：100～10000 毫秒，每轮在设定值的 ±20% 范围内重新随机，最低不低于 100 毫秒。
- **共用硬性冷却**：手动和自动的两次实际提交至少相隔 100 毫秒；词条未匹配也计算冷却。
- 禁止打字、没有有效敌人或输入界面不可用时暂停提交；关闭窗口或离开副本不会关闭自动模式，卸载插件会停止全部功能。

例如，延迟设为 100 毫秒时实际范围为 100～120 毫秒，设为 2000 毫秒时为 1600～2400 毫秒。

## 安装与使用

在 [Releases](https://github.com/Etest2023/KeyboundCompanion/releases) 下载发布包。在卫月设置-实验性功能-开发版插件位置中添加 `KeyboundClick.dll` 文件路径并保存。回到插件安装器-开发工具，启用即可
